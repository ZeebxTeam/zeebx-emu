# v0.6.0

The Z-Wheel now shows your games. The game grid and the 3D stage list what is in your ROM folder,
instead of the 59 titles the Zeebo store sold, and a game the store never had a slide for gets one
made from its box art and name. The Setup screen comes to life: the registration keyboard types,
the Shop no longer seems to hang, and message boxes read like the console's.

New:

- **The Z-Wheel's game grid lists the games you have.** Before, it always showed the store's 59
  titles in the same order, whatever the ROM folder held, and choosing one that wasn't there
  opened nothing. Now each game in the folder shows up once — with the store's box art and title
  when the store knew it, by its file name when it is a homebrew — and what is not in the folder
  doesn't show up. A game that comes back to the folder comes back to the grid, keeping its play
  count. With no game at all, the Z-Wheel shows its own notice, "Não há nenhum aplicativo em seu
  console"
- **The 3D stage follows the same list.** It showed the same fifteen slides for everyone, with
  Crash Bandicoot and Rally Master Pro twice. Now it shows one slide per game you have. Measured
  with 61 games: 12 with the store's own slide
- **A slide for every game.** A game the store had no slide for gets one made by the emulator: a
  framed panel with its box art and name, and its box art on the top reel. This is ours, not the
  console's — a Zeebo only showed what the store sent. Measured with 61 games: 48 slides made, no
  fault in 150 s on the stage
- **The registration on the Setup screen works**: the on-screen keyboard types and erases with the
  controller, the birth date lists move and keep the choice, and Back leaves the keyboard without
  crashing a few seconds later
- **Message boxes look like the console's**: the screen behind stays visible, long text wraps and
  scrolls with the arrows (with its scroll bar), and each text is drawn at its own size, with
  smooth edges

Bugs fixed:

- **Shop, Buy, Check balance and Refill card seemed to hang.** The Z-Wheel was already showing
  "Não foi possível conectar à rede", but releasing the key that opened the box closed it at once.
  The same release used to answer the language box on its own; now that box waits for your choice,
  and choosing "Sim" no longer crashes the Z-Wheel
- **Help and News crashed** as soon as they opened
- On the Setup screen, all the rows no longer move together, and the text of a box no longer hides
  under its frame
- **Zenonia** lost its box art and title in the Z-Wheel and showed up as a bare file name
- On Android, the folder picker, the access request and a few buttons are now shown in the chosen
  language

Still missing:

- the Z-Wheel needs the network for the Shop, the registration's "Confirmar" and the "Sim" in the
  no-games notice, and waits there forever; Navegar does not open
- a homebrew has no box art in the grid
- the slides made by the emulator take about 28 MB for 48 games, and a game's slide stays on disk
  after the game leaves the folder

For those working on the code: the codebase, its documentation and its build files are now in
English. The old Portuguese options of `zeebx` and `ZEEBX_*` variables keep working, and nothing
stored on disk changed names. The BREW core moved to the `zeebx-core` crate (0.1.2), and the game
heap size is now set by the emulator's loader.
