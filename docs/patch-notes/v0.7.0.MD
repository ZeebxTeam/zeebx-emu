# v0.7.0

A phone game runs on the Zeebo emulator: Devil May Cry: Dante x Virgil, which Capcom made for BREW
phones, now plays with its menus, its fights and its music. Games that shrink the picture and
stretch it back no longer draw a blank screen, the library on the computer gains a list view, and
you can choose to see each game by the name of its file.

New:

- **Devil May Cry: Dante x Virgil runs.** It is a game for BREW phones, not for the Zeebo, and
  four things stood in its way, each one a real difference between a phone and the console:
  - its menus did not answer the controller. Phone games now get the key events a phone sends,
    and the controller is mapped to the game's own default keys: D-pad to the arrows, 1 to
    confirm and evade, 2 sword, 3 gun, 4 jump, ZR style, HOME/Start and ZL the soft keys. The game
    still lets you change each action in HELP > KEY OPTION;
  - it stopped right after loading, at the first picture it decoded itself;
  - it played no sound at all. The title, mission select and mission songs now play;
  - it is drawn on its own phone screen, 240×400, instead of a thin column in the middle of a
    nearly white 640×480. In the computer version and in the RetroArch core the window shows
    just that screen, at its own proportions
- **Games that draw small and stretch the picture back** showed a blank rectangle where the game
  should be. The emulator now copies the frame into the picture the game asks for, with or
  without the graphics card
- **The library can be a list.** In the settings, "Library view" now has List, next to Grid and
  Slider: one game per row, with its box, its ClassID and its description. This is in the
  computer version
- **"Game names from the ROM files".** A new option in the settings shows each game by its folder
  or file name instead of the Z-Wheel's official name. It helps when the official name is wrong
  or drops the collection's prefix: with it, "Zeebo Extreme Baja" stays with the other Zeebo
  Extreme games instead of "Baja" going to the top of the list
- **The `zeebx run` command** turns the controller into console keys, like the window does. A
  game that reads keys, such as the debug menu of the Sonic Adventure port, used to sit in its
  menu without seeing any input

Bugs fixed:

- **A game could not render to a smaller area and let the screen scale it up.** The emulator
  answered the request in the wrong place, the game took that as a refusal and gave up on the
  feature
- **A silent piece of music** was refused and ended at once. Some games play one on purpose and
  waited for it, and called it again over and over. It now lasts as long as it should, in
  silence
- **The stable and the nightly versions offered each other as an update**, so the updater could
  ask you to go back and forth between them. Each one now only offers what is newer on its own
  channel
- The site now says the emulator runs on iPhone and iPad, and finds it when you search for them

Still missing:

- in Devil May Cry you get music or effects, never both. That is the game's own choice (OPTION >
  SOUND OPTION), not the emulator
- a phone game is shown at its own screen size only in the computer version and in the RetroArch
  cores. On Android, iPhone, the Vita, the Switch and the headless build it is centred on a black
  640×480 screen
- everything still missing in [v0.6.0](v0.6.0.MD) is still missing

For those working on the code: the BREW core is now `zeebx-core` 0.1.4. It follows the SDK's own
names for the interface slots and its order for `IFont`, and the documentation uses the SDK names
for `IGetLine` and `ISourceUtil`. `IDISPLAY_CreateDIBitmap` reads DIBs that the game describes and
fills in itself (`src/machine/guest_dib.rs`); `AEECLSID_SOUNDPLAYER` is served with
`RegisterNotify`, `SetVolume`, `GetVolume`, `SetInfo` and `GetInfo`; phone games are listed in
`src/input/phone.rs`, and `Session::display_screen` gives a frontend only the area the game draws.
`glCopyTexImage2D` and `glCopyTexSubImage2D` go through the `Rasterizer` trait, so both backends
have them. `IEGLSurfaceManip::SetSurfaceScale` now writes its result to `ret`. The licence notices
accept zeebx-core's GPL now that it comes from crates.io.
