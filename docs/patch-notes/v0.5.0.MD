# v0.5.0

> Rascunho: anota o que já entrou na `development` desde a v0.4.2.

**A interface antiga, em egui, saiu.** O emulador passa a ter uma interface só, a em Qt, que já
era a principal desde a v0.4.0 e é a que recebe as novidades.

Para quem usava a interface em egui (o programa `zeebx`, o pacote `zeebx-standalone-egui` ou o
cask `zeebxteam/tap/zeebx`):

- ela fica na v0.4.2 e **não vai receber atualizações**. O emulador não troca uma interface pela
  outra sozinho;
- para continuar recebendo as versões novas, instale a interface em Qt pela página de releases
  (`zeebx-standalone-qt-…`) ou pelo cask `zeebxteam/tap/zeebx-qt`. As configurações, a pasta de
  jogos, os saves e os save states são os mesmos, e ela os encontra sem fazer nada;
- depois, a versão em egui pode ser desinstalada.

Para quem mexe no código: a linha de comando (`zeebx run`, `zeebx sessao`, `zeebx bench`) continua
existindo, agora em `frontends/cli`, e compila sem o Qt.
