# v0.2.1

Bugs fixed:

- Red fog in Resident Evil 4: the fog color lost its green and blue
- Action Hero 3D threw an error after a few minutes into a stage: the game ran out of memory
- The music in the Zeebo Extreme games restarted on every boost or drift
- Crash Nitro Kart: the next section of the track appeared suddenly instead of being seen through
  the portal ahead of time, with the graphics card on
- Games that ask for OpenGL functions through `eglGetProcAddress` got functions with shifted
  arguments, and the buffer ones with the `ARB` suffix weren't found
- Meshes stored in a vertex buffer starting from the beginning of the buffer weren't drawn
- The texture environment's `GL_COMBINE` mode was treated as `GL_MODULATE`
- Fan-made ports, like OpenTyrian and Aviãozinho, stopped after the first screen: the data
  requested through `fs:/mod/` wasn't found, the sound generated by the game itself was refused,
  and a read through a null pointer, which the console tolerates, closed the game
- Quake in slow motion: the window ran at most one game frame per window frame, and each polygon
  went to the graphics card on its own. Now a game that falls behind catches up on frames and the
  draws go in batches
- Quake in 16:9 got smaller instead of wider; with the internal resolution above 1, also in 4:3
- Left and down on the D-pad swapped in games that read the button by position, like the SDK
  samples
- Only the first texture unit was drawn, and the emulator claimed to have just one: games that
  combine two textures (bump, light map) fell back to simplified paths or disappeared
- Long sessions used more and more memory: bitmaps, sounds, the game log and the controller queue
  grew without limit

New:

- Dragon Vs Chicken, the Zeebo SDK demo, runs with the characters and the full scenery

- The Boomerang uses the motion sensor of the controller chosen on the port: Pro Controller,
  DualShock 4 and DualSense, besides the Wii Remote. When the system doesn't allow reading the
  sensor, a button creates the permission
- The Wii Remote is a controller like the others: you can use it as a Z-Pad and map its buttons
- Search in the top bar: filters the library by name, ignoring accents (Ctrl+F)
