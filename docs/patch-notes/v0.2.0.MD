# v0.2.0

Added compatibility with:

- Action Hero 3D
- Alice no País das Maravilhas
- Alien Breaker Deluxe
- Bad Dudes vs. DragonNinja
- Disney All Star Cards
- Heavy Barrel
- Iron Sight
- Peggle
- Tork and Kral
- Turma da Mônica em Vamos Brincar Vol. 1
- Um Jogo de Ovos
- Zeebo Extreme Jetboard
- Zeebo Extreme Rolima

New:

- In-game fog, with an option in the graphics settings to turn it off

Bugs fixed:

- Audio in Data East games
- Controller not recognized in some games, which got stuck on the menu
- Games that opened and closed by themselves right at loading
- Wrong or white images in several games: PNG delivered in a different format from what the game
  expects, compressed BMP and odd-width images
- Text and effects drawn over the whole screen instead of clipped
- Swapped buttons in the Data East arcade games: 2 responded as the right trigger, 4 as 3, and the
  controller's 2 and 3 did nothing
- Uncalibrated analog stick on controllers that only ask for calibration when connected
- Port 2 responding to the port 1 controller when both devices are the same model
- Two players not being recognized: port 2 read the same controller as port 1, and the game never
  saw a second player
- Games freezing after a while of play from running out of memory, like Treino Cerebral when
  entering the second stage
- Controller stopping responding in some games with both ports connected
- Zeeboids saving the photo upside down with 3D on the graphics card, which left the character
  flipped in the other games too
- A strip on the right of the screen in 16:9 in some 3D games, like Resident Evil 4 and Crash
  Nitro Kart 3D
