# v0.5.1

Uma versão de segurança. Um jogo aberto no emulador podia ler, sobrescrever e apagar arquivos
fora da própria pasta. Agora cada jogo enxerga só o que é dele, e os saves de todos os jogos
passam a ficar num lugar só.

Bugs corrigidos:

- **Um jogo não alcança mais os arquivos do computador.** Um `.mod` aberto fora de um pacote,
  direto de uma pasta como `Downloads`, podia mexer nos arquivos ao lado dele: ler, trocar o
  conteúdo e apagar. Num pacote `.zip`, podia apagar arquivos do próprio jogo. Nenhum jogo da
  biblioteca faz isso, mas um `.mod` de origem desconhecida faria. Agora:
  - o jogo só lê o que veio com ele, e não consegue alterar nem apagar esses arquivos;
  - tudo o que o jogo grava vai para a pasta de saves do emulador;
  - atalhos (links simbólicos) dentro da pasta do jogo são ignorados;
  - um save state alterado à mão não reabre arquivos fora do que o jogo alcança.
- **Os saves de todos os jogos ficam juntos**, em `saves/mod/`, uma pasta por jogo, como no
  console. Um jogo que usa o save de outro, como o Zeebo F.C. com os bonecos do Zeeboids,
  continua encontrando o que precisa
- **O progresso do Quake fica guardado com os outros saves.** Antes ele ia para a pasta do jogo
  extraído e se perdia quando ela era apagada
- **Armageddon Squadron**: o terreno não aparece mais dividido em retângulos claros e escuros. A
  luz dos jogos 3D caía do lado errado dos objetos girados, e no terreno, desenhado em blocos,
  isso virava sombra fora do lugar. Vale para todo jogo que ilumina a cena pelo console

Para quem já tinha saves:

- na primeira vez que cada jogo abre nesta versão, os saves dele são copiados para o lugar novo
  sozinhos. Nada é apagado: a cópia antiga fica onde estava, e nenhum save do lugar novo é
  sobrescrito
- duas versões do mesmo jogo passam a dividir o mesmo save, como dividiriam no console
- um save state feito numa versão anterior com o jogo gravando num banco de dados pode não
  carregar. Isso não afeta o save normal do jogo
