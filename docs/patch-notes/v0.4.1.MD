# v0.4.1

A bug-fix release. On the computer, the previous version could erase game progress, and on some
handhelds the RetroArch screen stayed black. And Ridge Racer, Zuma's Revenge, Powerboat
Challenge, Prey Evil, Peggle, Heavy Weapon and Reckless Racing become playable.

Added compatibility with:

- Ridge Racer: the menus and the race HUD (position, times, speedometer, map) show up, and the
  game no longer closes with an error when leaving the title screen
- Zuma's Revenge
- Powerboat Challenge: gets past the loading screen, and the game stops erasing the options save
  every time it opens with the warning that it was corrupted
- Quake 2: the game no longer freezes when starting a level, and the scenery shows up — before,
  only the health HUD stayed on screen
- Prey Evil: the menus show the full names, and not just the first letter of each option, and
  the sound no longer turns into a repeated hiss as soon as the game opens
- Peggle: the colors are the game's again (the sky came out pink and the logo blue), and the
  background behind the logo on the menu is no longer black
- Zuma's Revenge: the sky on the loading screen, the menu background and the level scenery no
  longer come out in stripes
- Toy Raid: the helicopters facing right, the planes and the explosions no longer show up inside
  a black rectangle
- Heavy Weapon: the colors are the game's again
- Reckless Racing: the cars' shadow and the track's no longer come out in stripes
- Iron Sight: the game no longer closes with an error when going from the menu to the first level

Bugs fixed:

- **Saves erased on the computer.** Zeebx keeps an uncompressed copy of each game opened and,
  when those copies went over 512 MB, it erased the oldest ones. Each game's progress lived inside
  that copy and went away with it. Now progress stays in a folder of its own, `saves`, inside the
  Zeebx configuration folder, and what a previous version saved is brought there the first time
  the game is opened. Saves already erased by this bug don't come back
- In the saves list, games like Crash Nitro Kart and Need for Speed showed up with dozens of
  megabytes of "save", because the game's own files were counted as progress. Deleting that save
  deleted the game along with it. Now the list shows only what the game saved
- In RetroArch, on Linux handhelds that use OpenGL ES, the screen stayed black with the sound
  working when the game was drawn on the graphics card
- In the egui interface, with 3D drawn on the graphics card, the image came out squeezed into a
  corner of the window and the transparent parts of images turned into white boxes
- In the egui interface, with the frame going to the screen through the graphics card, games that
  only draw in 2D, like Bejeweled Twist, had a black screen
- Need for Speed Carbon: in the intro, the EA logo came out cut diagonally and the trademark
  notice cut in half, when 3D is drawn on the processor

Android, RetroArch and iOS already kept progress separately and didn't have the erased saves
problem.
