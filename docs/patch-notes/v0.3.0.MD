# v0.3.0

The biggest update since the start of the project. The emulator is no longer a single program:
there are now four ways to run the same core.

New:

- **Libretro core.** Zeebx runs inside RetroArch, on Linux, Windows and macOS, x86_64 and ARM64.
  It draws on the graphics card when the frontend offers a context and falls back to the
  processor when it doesn't, without losing features. It comes with save states, keyboard, the
  navigable Z-Wheel and the associated No-Intro database, which names the games and finds the
  covers
- **Android app.** The library as a grid with covers, the full settings, the folder picker and the
  speed panel, with 3D on the device's graphics chip. The interface was redone for the hand, and
  it responds to the controller: the D-pad moves through the grid, the header, the options and the
  pause menu
- **Version without an interface** (`headless`), for those with their own frontend: configured
  through `config.ini`, with no settings window
- **Handhelds.** R36S, R35S and RGB20S (ArkOS and derivatives) and RG40XX-H (muOS) get the core
  ready to go, with an installer that takes care of the SD card
- **Complete save states**: registers, memory, objects, textures, the 3D state and the clock,
  with an integrity check
- **Games in `.7z`**, besides `.mod` and `.zip`
- **MIDI with a soundfont.** An `.sf2` in the device folder and the music comes out of the
  synthesizer; without it, it stays as before
- **Spanish built in**, with a Mexican variant — that makes four languages
- Windows ARM64 gets its own build

Added compatibility with:

- Prey Evil
- Zuma's Revenge

Bugs fixed:

- Turma da Mônica games were silent: 86 Ogg/Vorbis sounds weren't decoded
- Peggle with seven tracks without sound: the MP3 tag lied about the file size
- A click at the end of every sound effect, in every game
- MIDI music freezing the game for six seconds on every track change
- Zeebo Extreme Rolimã running at 79% of the console's speed; now it goes past it
- Game text not showing up, because the device font was missing
- Wrong images in games that ask for the decoder by another name
- Stick not read in games that ask for it through IJoystick
- Skewed lines in textures of unusual width
- Widescreen, internal resolution, antialiasing and anisotropic filtering did nothing with 3D on
  the processor; now they show up grayed out when the graphics card is off, which is the truth
- `.deb` that wouldn't install on a minimal system, because it didn't declare the window libraries

Android only:

- D-pad direction getting stuck after letting go
- Controller that didn't move the cursor in the library, the header, the options or the pause menu
- Button 2 that didn't go back
- Leaving the game through its menu showed an error message, as if something had broken
- Crackling and delayed sound on the device
